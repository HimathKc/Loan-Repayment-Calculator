# Loan Repayment Calculator

A C++ console application that calculates monthly loan repayments and generates a detailed amortization schedule.

## Features

- Calculates monthly repayment amount
- Supports different loan types: Micro, Standard, and Premium
- Displays total interest and service fees
- Generates a monthly repayment schedule
- Shows a final financial summary

## Technologies Used

- C++
