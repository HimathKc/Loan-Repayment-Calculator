# Loan Repayment Calculator

A C++ console application that calculates monthly loan repayments and generates a detailed amortization schedule.

## Features

- Calculates monthly repayment amount
- Supports different loan types: Micro, Standard, and Premium
- Displays total interest and service fees
- Generates a monthly repayment schedule
- Shows a final financial summary

## Technologies Used

- C++

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/HimathKc/Loan-Repayment-Calculator.git
```

2. Open the project folder:

```bash
cd Loan-Repayment-Calculator
```

3. Compile the program:

```bash
g++ loan_repayment_calculator.cpp -o loan_calculator.exe
```

4. Run the program:

```bash
loan_calculator.exe
```

## Example Input

```text
Enter principal loan amount: 10000
Enter your total number of monthly payments: 12
Enter your annual interest rate: 2
```
